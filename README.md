# AI Tech Marketplace — Frontend

React frontend for AI Tech Marketplace.

## Technology

* React
* TypeScript
* React Query
* Zustand
* React Router
* WebSocket

## Responsibilities

The frontend provides:

* Product browsing
* Product search
* Product filtering
* Product details
* Authentication
* Shopping cart
* Checkout
* Order management
* AI Shopping Assistant
* Admin dashboard

## Architecture

```text
React
  |
  ├── REST API
  |
  └── WebSocket
        |
        v
     Backend
```
